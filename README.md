# Sing-box Linux 多协议综合节点管理脚本

一款轻量、极速且高度模块化的 **Sing-box** 多协议节点与多出口路由管理脚本。支持 **6 大主流协议**、**Cloudflare Argo 隧道穿透**、**WARP 智能分流/全局出站**、**Psiphon 赛风 28 国多出口独立副节点组** 以及 **自定义外部代理出站中转**。

---

## 🌟 核心特性一览

### 1. 主节点多协议群 (多协议并存)
- **VLESS-Reality**：原生 TCP + Vision 流控，默认伪装 `apple.com`，抗封锁性能优异。
- **Hysteria2**：基于 UDP/QUIC 协议，针对弱网与高丢包线路深度优化。
- **TUIC v5**：基于 QUIC 协议并集成 BBR 拥塞控制。
- **VMess-WS**：支持 WebSocket 传输与 Cloudflare CDN / Argo 隧道穿透。
- **Trojan-WS-TLS**：WebSocket + TLS 加密传输。
- **AnyTLS**：Sing-box 新一代特色加密协议。

### 2. 主节点出站灵活调度
- **原生直连出站 (Direct)**：使用 VPS 原生公网 IP 访问。
- **WARP 全局双栈出站**：主节点全部 IPv4 与 IPv6 流量经 Cloudflare WARP 出口（全面隐藏真实 IP，支持 Endpoint 优选）。
- **WARP 仅 IPv4 出站**：仅 IPv4 流量走 WARP 出口，IPv6 保持原生直连。
- **WARP 仅 IPv6 出站**：仅 IPv6 流量走 WARP 出口，IPv4 保持原生直连（特别适合纯 IPv4 VPS 解锁 IPv6 网络服务）。
- **WARP 规则分流**：Google / YouTube / Netflix / OpenAI 等流媒体与 AI 服务走 WARP，其余直连。
- **Psiphon 赛风出站**：主节点流量经由 Psiphon 赛风隧道出口（支持 28 国地区切换与智能优选）。
- **自定义外部代理出站 (OpenRung 等 VLESS-Reality)**：直接粘贴外部代理链接（VLESS-Reality / Hysteria2 / TUIC / Trojan / VMess / Shadowsocks），主节点全部流量经外部中继出站（如 OpenRung 分布式中继网络），进一步隐藏 VPS 真实 IP，适用于主节点需要多级跳转或解锁场景。

### 3. 副节点系统 (平行独立、专属入站与出口)
- **赛风多出口副节点组**：可自由添加指定国家（如 US, JP, SG, HK, KR, TW, DE, GB 等 28 国）的赛风副节点组，各出口组配备独立的本地入站端口（Hy2 / TUIC / Reality），与主节点互不干扰。
- **副节点出站双模式支持**：
  - **纯赛风原生出站**：客户端流量直达对应国家的赛风官方网络出口。
  - **赛风（WARP 前置 / Cfon 出站）**：采用 Oblivion / Cfon 架构，由 Cloudflare WARP 作为赛风的底层前置加密传输通道，大幅增强抗阻断能力，最终出口保持在所选国家。
- **自定义外部代理副节点组**：支持导入外部代理节点（VLESS / VLESS-Reality / VMess / Trojan / Shadowsocks / Hysteria2 / TUIC），自动配置专属本地入站中转。VLESS-Reality 链接自动解析 Reality 公钥 / short_id / SNI / flow，可直接导入 OpenRung 等中继节点。
- **OpenRung 中继一键接入 + 自愈**：自动抓取 OpenRung Broker 最新中继列表并按国家分类建组（每个国家独立节点组，自动保存该国全部备用中继）；每分钟自动探测各中继出口 IP，失效自动切换同国备用中继并重建配置，全程轻量探测（严格超时 + 用完即杀 + 自动清理缓存，绝不占用服务器资源）。
- **免费节点池一键接入 + 自愈**：支持自由部署的免费节点池订阅（如 Cloudflare Workers 拉取/筛选举的免费节点，按国家重命名后分发）一键接入，交互式输入订阅地址与密钥（脚本不内置任何地址，源码公开安全）；订阅节点自动按国家/地区分类建组，每分钟自动探测出口，失效自动切换组内下一个节点并重建配置，全程轻量探测。

### 4. Cloudflare Argo 隧道穿透
- 自动部署并管理 Cloudflare Argo 临时隧道，无需自有域名与公网开放端口，即可实现全球 CDN 加速与流量穿透。

### 5. 极速探测与防僵尸进程保护
- 内置毫秒级单行动态握手探测，拒绝黑屏卡死假象。
- 完善的子进程状态回收 (`wait`)、信号陷阱 (`trap`) 与全自动垃圾清理机制，杜绝 `<defunct>` 僵尸进程与 PID 耗尽问题。

### 6. TCP / UDP / BBR 网络底层深度调优 (源自 tcp.vpsing.de)
- **IPv4 优先解析**：解决双栈 VPS 因 IPv6 绕路导致的节点连接握手卡顿。
- **BBR + FQ 拥塞算法**：内核级降低跨境丢包率，大幅拉升单线程吞吐与 YouTube 4K 播放流畅度。
- **生产级 + 跨境专属内核调优**：动态分配物理内存 5% 网络缓冲、削减 Reality/VLESS 首包延迟 (TTFB)、开启 MTU 智能探测、深度扩容 UDP 缓冲区防 Hysteria2/QUIC 高并发丢包、启用 ECN 智能标记、突破百万级文件句柄 (1048576)。
- **网卡多队列均衡 (RSS/RPS)**：打破 CPU 单核软中断 (SoftIRQ) 瓶颈，将大并发流量均匀平摊至全核。
- **快捷指令**：终端输入 `t` 或 `sb tcp` 即可直接拉起调优看板。

### 7. 服务自愈与快捷管理
- 内置 `cron` 每分钟健康自愈守护任务，主副节点掉线自动拉起与阶梯 Fallback 换路。
- 终端输入 `sb` 即可调出多排结构化管理控制台；输入 `t` 打开网络性能看板。

## 🚀 快速安装与使用

### 一键安装命令

在任意 Linux 服务器（支持 Ubuntu, Debian, CentOS, AlmaLinux, RockyLinux, Alpine 等）上以 `root` 权限执行：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/hxzl666/singbox/main/install.sh)
```

---

## 📋 快捷管理命令：`sb` 与 `t`

安装完成后，在终端任意位置输入 `sb` 即可进入管理控制台：

```bash
sb
```

快捷打开网络调优控制台：
```bash
t
# 或
sb tcp
```

## 🛠️ CLI 常用快捷调用

| 快捷命令 | 说明 |
| :--- | :--- |
| `sb` | 进入交互式管理控制台 |
| `t` / `sb tcp` | 直接打开 TCP / BBR / 网卡网络深度调优面板 |
| `sb update` | 强制拉取 GitHub 最新版本并热更新本地脚本 |
| `sb show` | 查看主节点分享链接与配置信息 |
| `sb all` | 查看主节点与所有副节点的分类汇总总览 |
| `sb restart` | 重启 Sing-box 并同步所有出站配置 |
| `sb reconfig` | 快速重新配置主节点协议与端口 |
| `sb cron` | 执行一次后台健康检查与自愈 |

## ❌ 彻底卸载

如需完全删除所有组件、清理服务守护及配置文件，可在 `sb` 菜单中选择 `15`，或直接执行：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/hxzl666/singbox/main/uninstall.sh)
```
